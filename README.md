# lalitasahasranama.com

The 1000 names of Śrī Lalitā, one page per name, with meaning in layers (word by word,
explanation, inner meaning, story and commentary), audio, and the names in ten Indian scripts.
Built with [Astro](https://astro.build) as a static site.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # checks content, then writes the site to dist/
npm run preview    # serves dist/ locally
```

## How it is organised

- **Content** lives in `content/`: one JSON file per name (`content/names/0001.json`) and
  `content/verses.json`. Nothing about the names is written in code.
- **Only Devanagari is stored.** Telugu, Tamil, Kannada, Malayalam, Bengali, Gujarati, Odia and
  IAST are generated by `src/lib/translit.mjs`.
- **Pages**: English at `/name/4-chidagni-kunda-sambhuta/`, Hindi at `/hi/name/4-chidagni-kunda-sambhuta/`,
  plus a page per verse (`/verse/1/`), a list of all names (`/names/`) and `sitemap.xml` with hreflang links.
- **Other languages** (Telugu, Tamil and the rest) are readable on every page through the
  language buttons. They get their own pages once their content is written: see AGENTS.md.
- A name gets a page in a language only when **every layer** is written in that language,
  so thin, half-translated pages never reach Google.

## Content status

All 1000 names are written in English and Hindi, every layer, as **drafts**. Claude wrote them
from the master text (stotranidhi.com) and Bhāskararāya's *Saubhāgya Bhāskara* (Sanskrit
Wikisource edition). Each commentary quote was checked by machine, word for word, against that
edition. No scholar has reviewed them yet, so every page shows a draft notice.

- `content/TEXT-NOTES.md` lists the sources, variant readings and corrected archana forms.
- Each name file's `review.notes` lists what a scholar should check for that name.
- After review, set `"review": { "status": "reviewed", "reviewedBy": "…" }`.

`AGENTS.md` is the brief for a coding agent (Claude Code, Codex or others). Use it to add
other languages or correct names, one verse or a small batch at a time.
`npm run validate` prints how many names exist and how complete each language is.

## Audio

Put recordings in `public/audio/`, for example `public/audio/chant/0004.mp3`, and set
`"audio": { "chant": "/audio/chant/0004.mp3", "slow": "/audio/slow/0004.mp3" }` in the name file.
Until a name has recordings, its buttons use the visitor's device voice for Hindi, where available.

## Deploying

Any static host works (Cloudflare Pages, Netlify, Vercel, GitHub Pages): build command
`npm run build`, output folder `dist`. "Today's name" on the home page is chosen when the site
is built, so schedule one rebuild a day (most hosts offer a deploy hook you can call on a schedule).
